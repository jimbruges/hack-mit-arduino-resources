Challenge description

Presented by Arduino

Touch Grass: Build Something That Understands the Real World

The most revolutionary software in the world is useless if it can't feel the world.

Code lives in the abstract. Light, temperature, sound, pressure, motion, humidity—that's reality. Now it's time to build systems that understand the physical one. This challenge asks you to build the bridge between them.

Using the Arduino® UNO™ Q, you'll pull raw, messy, beautiful data from the physical environment around you and turn it into something that matters: a tool that helps someone, an experience that surprises someone, a system that understands the world a little better than it did before.

The best projects won't just visualize sensor data, they'll transform it into meaningful, intelligent experiences.

Core requirements

  • Arduino UNO Q as your primary hardware platform
  • At least one physical sensor ( Modulinos) detecting real-world data
  • Sensed data must meaningfully drive your application, not just display raw numbers
  • Must be demonstrable with live, real-time sensor input during judging
  • Software: Use the Arduino App Lab.

Your project shouldn't be able to exist without the physical world it senses. If you can remove your sensor and your project still works, start over!
