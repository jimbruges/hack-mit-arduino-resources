# Arduino UNO Q Resources

A simple GitHub Pages site with curated Arduino UNO Q, Qualcomm AI, and HackMIT
resources to help participants move from hardware setup to a working prototype.

## Run locally

No build step is required. Open `index.html` directly, or serve the directory with:

```sh
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Publish with GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, and
choose the repository's default branch and the `/ (root)` folder.
